# Gari8 Tap

## How do I install these formulae?

`brew install gari8/tap/<formula>`

Or `brew tap gari8/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gari8/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
